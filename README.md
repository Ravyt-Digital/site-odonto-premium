# Odonto Premium

Landing page institucional responsiva para uma clínica odontológica premium.

## Executar localmente

O projeto não requer instalação de dependências. Inicie qualquer servidor HTTP na raiz:

```bash
python3 -m http.server 4173
```

Depois, abra `http://localhost:4173` no navegador.

## Estrutura

- `index.html`: conteúdo e estrutura semântica da página.
- `styles.css`: identidade visual, layout e responsividade.
- `script.js`: menu móvel, carrossel de depoimentos e formulário.
